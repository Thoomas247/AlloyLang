
- What does the @ unary operator do? It doesn't reach the code generator as a unary operator, currently these instructions do exactly the same thing:

	// array of i64 from ptrArray
	const arr : [i64; 3] = { ptrArray[0], ptrArray[1], ptrArray[2] };
	OR
	const arr : [i64; 3] = { @ptrArray[0], @ptrArray[1], @ptrArray[2] };

X How do we insert CR or LF in a string ? printf("\n") outputs: \n

X Need to add support for functions with variable arguments using ...

X A return statement with no return value causes an "Invalid ID" error, e.g.:
	fn process(const a : &i64) {
		printf("a = %f\n", a);
		return;
	}

- Need support for hexadecimal, octal, binary ... integers

X This statement is not parsed correctly: 
	var test : i64;
